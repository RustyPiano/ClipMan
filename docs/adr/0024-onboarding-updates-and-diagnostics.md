# 0024 首次启动引导、自动更新、即时保存的设置与诊断日志

- 状态：已采纳（2026-11-27）

## 背景

新用户启动 ClipLeaf 后看不到任何窗口（窗口默认隐藏，macOS 上不显示 Dock 图标），辅助功能权限要等第一次自动粘贴失败才提示。更新只能在“关于”页手动检查。设置页需要手动保存，主题却立即生效。发布版的日志只写到 stderr，用户反馈问题时拿不到日志。

## 决定

- `settings.onboarding_completed` 记录是否看过欢迎页。`settings.json` 不存在或为空、默认数据目录里也没有历史数据库（`clipleaf.db` 或 `clipman.db`）时才是首次启动，取值为 `false`，并立即写入 `settings.json`，用户没点“开始使用”就退出时下次仍显示欢迎页。旧版本一直使用默认设置时不会写 `settings.json`，所以要同时看数据库；旧版本保存的设置缺少这个字段时也按已完成处理，升级用户不会看到欢迎页。`Settings::default()` 取 `true`，恢复默认设置不会重新触发引导。这个字段只由 `complete_onboarding` 修改，`update_settings` 和重置都保留现值。
- 欢迎页叠在 QuickBar 上（`Onboarding.svelte`），页面加载后自己调用 `show_quickbar`。不在 `setup()` 里显示：应用启动激活的过程中窗口会失去焦点，被失焦隐藏的逻辑立即收起。欢迎页只在用户点击“开始使用”后完成。按 Esc 只隐藏窗口，下次打开仍显示欢迎页。欢迎页显示期间 QuickBar 的键盘处理只响应 Esc，欢迎页背后的控件设为 `inert`，Tab 不会把焦点移到看不见的控件上。
- 点击“去授权”会切到系统设置，QuickBar 因失焦隐藏。欢迎页未完成时，后端在 180 秒内每 500 ms 检查一次辅助功能权限，授权后重新显示 QuickBar（`show_onboarding_when_trusted`）。
- macOS 上申请辅助功能权限时调用 `AXIsProcessTrustedWithOptions`（带 prompt），再打开系统设置的辅助功能页。只打开设置页时，ClipLeaf 不在列表里，用户要手动添加。权限提示文案同时覆盖“从未授权”和“更新后失效”，因为系统无法区分这两种情况。
- 更新检查在 Rust 端完成（`updates.rs`）：启动 30 秒后检查一次，之后每 24 小时检查一次，可在“关于”页关闭（`auto_check_updates`）。已经发现新版本也继续检查，用户暂缓安装期间又发布修复版时提示会换成最新版本；只在安装中和安装完成等待重启时停止检查。找到的 `Update` 保存在 `UpdateState` 里，安装时复用，界面显示的版本就是实际安装的版本。有新版本时托盘菜单增加“安装新版本”，QuickBar 底栏显示提示，二者都打开设置窗口的“关于”页（`settings-open-tab` 事件）。
- 安装分两步：`install_update` 下载并安装，通过 `update-progress` 事件报告进度；完成后由用户点击“立即重启”（`restart_app`）。Windows 安装程序会在安装步骤自动退出应用。“已安装、等待重启”由后端保存（`UpdateInfo.readyToRestart`），设置页切换标签或重新打开后仍显示重启按钮，托盘菜单换成直接重启的“重启以完成更新”，再次调用 `install_update` 会被拒绝。
- 设置页即时保存：任何修改在 300 ms 后提交完整设置。保存进行中又有修改时，当前请求结束后再提交一次。后端拒绝时提示错误，界面恢复到上次保存成功的值。保存进行中确认的重置同样排队，在当前请求结束后发出。文本框和数字框在 change 时提交，数字框先通过浏览器校验，不合法的值不提交。关闭设置窗口（`settings-hidden`）时立即提交尚未发出的修改。历史记录数量的滑块拖动时只更新显示的数字，松开（change）才提交；新上限会删除未收藏的记录时先确认要删除的条数，取消则滑块回到原值。
- 日志使用 `tauri-plugin-log`，同时写到 stdout 和系统日志目录下的 `clipleaf.log`，单个文件上限 2 MB，保留 3 个。插件在 single-instance 之后注册，`tauri::Builder` 之前的日志不会写入文件。panic hook 在 `panic = "abort"` 终止进程前把 panic 信息和 backtrace 写进日志。日志不记录剪贴板内容。
- 收藏导出先写入同目录的临时文件，写完并 `sync_all` 后再替换目标文件，磁盘写满时原有的备份不受影响。导入前校验每一项：文件列表必须是 JSON 字符串数组，图片和缩略图必须能解码，任何一项不合格整个文件都不导入。内容与已有收藏相同的跳过；与未收藏的历史记录相同时把那一行设为收藏，并补上它缺少的 HTML、缩略图和标签。
- “关于”页的“复制诊断信息”只包含版本、系统、条目数量、数据库大小和设置摘要，不包含剪贴板内容、忽略的应用名称和数据路径。

## 影响

新增设置字段 `onboardingCompleted`、`autoCheckUpdates`，前端类型在 `src/lib/types.ts`。设置页不再有“保存”按钮和返回按钮，“托盘菜单”并入“常规”页。
