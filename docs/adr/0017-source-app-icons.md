# 0017 来源应用图标

- 状态：已采纳

## 决定

- 图标按应用名存在 `app_icons` 表，每个应用一份。来自同名应用的旧记录也能显示图标。
- 每个应用在一次运行中只渲染一次图标（`SAVED_APP_ICONS`），应用更新后的新图标在下次启动时覆盖旧图标。
- 图标画进 64px 位图再编码为 PNG，列表里以 12–16px 显示，2x 屏幕也够用。创建位图时 planes 传空，由 AppKit 分配像素内存，颜色空间名用 AppKit 导出的常量；编码 PNG 时使用空属性字典。
- 图标只影响显示：渲染或保存失败只记日志，本次复制照常保存。
- 前端 `appIconStore` 按应用名缓存结果，读取失败时缓存 null，不在每次渲染时重复请求和提示。收到 `app-icon-saved` 后 `invalidate` 清除该应用进行中的请求，之后才返回的旧结果不写入缓存。
