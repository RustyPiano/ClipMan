# QuickBar 接收输入时保留目标应用的编辑状态

已采纳。适用于 `window.rs`、`accessibility.rs`、`paste.rs`、`main.rs` 和 QuickBar 前端。

## 原生窗口和输入

单实例插件最先启动，避免两个进程争用监听器和快捷键。再次启动时通过主线程显示已有 QuickBar。IPC 和工作线程需要将 AppKit 窗口操作调度到主线程。Accessory 激活策略在 Tauri 创建 NSApplication 后设置。启动失败且没有 AppState 时先销毁可能发起 IPC 的隐藏窗口，后台线程等待用户确认错误；setup 必须先返回，事件循环才能显示对话框。

macOS 的无边框面板必须能成为 key window 以接收搜索输入，同时让访达保持激活和改名状态。tao 创建 NSWindow 子类。ClipMan 在设置 NonactivatingPanel 之前通过 `object_setClass` 换成 NSPanel 子类，让 NSPanel 处理样式变更。原实现记录的布局依据是 macOS 26 上 NSPanel 与 NSWindow 实例大小相同（528 字节），新子类不增加实例变量。tao 的窗口增加 focusable 状态并覆盖聚焦和背景拖动行为，QuickBar 不依赖动态设置 focusable 或背景拖动。更换 tao 或 macOS 版本时需要复核这些前提。

运行中修改样式后，使用 AppKit 私有接口 `_setPreventsActivation:` 同步 WindowServer 的鼠标激活行为。显式调用 tao 的 `set_focus` 会激活应用。原生 QA 通过屏幕窗口和高度过滤判断面板可见性，点击顶部空白处，验证搜索输入仍可用、目标仍在前台以及访达改名框仍能接收粘贴。

按光标所在屏幕的工作区和缩放因子计算尺寸与位置。光标位置不可用时依次使用窗口所在屏幕和主屏幕。配置中的初始尺寸用于创建窗口，显示时按目标显示器调整。面板表面保持不透明，窗口背景透明。macOS 窗口服务器按 alpha 边界在窗口外绘制阴影，显示或调整尺寸后需要刷新。外围 CSS 半透明像素会导致灰边；Windows 的 DWM 阴影沿矩形边框，保持关闭。Windows 通过原始窗口句柄衔接不同版本的 windows crate。

macOS 发送 Cmd+V 前先查辅助功能授权，因为缺少授权时 CGEventPost 可能静默失败。复制已完成，用户仍可手动粘贴。主线程只显示一个授权对话框，QuickBar 在收到拦截事件及重新获得焦点时更新提示。其他平台共用命令接口。将等待目标恢复的操作放到阻塞线程池；QuickBar 已重新打开时停止发送按键。使用物理 V 键码 9，避免 enigo 在工作线程通过 TSM 查询输入源而触发主队列断言。

快捷键对调时先注销所有变更的旧绑定。回滚先释放新绑定再恢复旧绑定，保留原始错误并记录回滚失败。录制结束或组件卸载时，等待禁用完成再恢复快捷键。

## 历史、选择和预览

只有 QuickBar 初始化历史订阅。先订阅再查询，将加载期间到达的复制事件叠加到查询结果。刷新保留已加载的页数，打开窗口或切回最近列表时收回额外页。每次多查一行判断是否还有下一页。追加分页有独立的请求序号，按 ID 去掉加载期间已移动的行。每个请求只清理自己仍持有的加载状态。清空历史后的缓存清理和重载由后端事件驱动。

搜索查询变更会使旧请求失效。同一查询共享进行中的请求，后台刷新保留列表和搜索图标状态。同词刷新失败时保留已有结果，新词查询失败时清掉旧结果。刷新期间如再收到作废通知，重新读取历史后再刷新搜索。预览只有选择稳定后才读取正文，小型文本或路径详情可缓存，原图和超大详情按需读取。截断的文本不显示不完整的字符数。应用图标请求以应用名和请求身份区分，失效后迟到的结果不能覆盖新图标；缺失或读取失败记为 null，避免每次渲染重试。

行高共用 rem 常量，保证方向键滚动、CSS 和虚拟列表位置一致。用透明边框给相邻选中项留缝，保持行高。元信息用字符串连接，避免 WebKit 在模板换行处渲染额外空格。为行操作预留宽度，稳定的操作 ID 保持按钮焦点。复制反馈随行卸载结束。相对时间共用时钟，隐藏窗口中的行可以继续更新。

普通方向键清空多选，Shift 选择从锚点到光标的连续区间，缩回一行时清空多选。第一次 Shift 点击建立锚点。按键使用勾选的唯一行或按选择顺序合并，删除光标行后保留原位置。输入法结束组字时仍可能发出键码 229，应把该次回车留给输入法。粘贴失败的提示按实际动作选词，默认动作遵循自动粘贴设置，反向动作取反。

语言随后端设置同步，TypeScript 的粘贴格式与 Rust 枚举值一致。系统主题模式订阅系统外观变化，离开时取消订阅。原生模态对话框限制背景交互并支持 Esc；普通确认默认聚焦确认，迁移默认聚焦取消。新的确认请求先结束上一个等待者。迁移成功只更新数据路径，保留尚未保存的其他设置。
