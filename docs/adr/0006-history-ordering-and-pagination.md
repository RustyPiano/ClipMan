# 0006 历史排序与分页

- 状态：已采纳

## 决定

- 时间戳是小数 Unix 秒（Rust `f64`、JS number），同一秒内的采集和使用也能保持先后顺序。SQLite 同时读取旧的整数秒和新的小数秒，不改写旧行。
- 最近列表用 keyset 分页。游标是已加载最后一行的 `(timestamp, id)`，排序为 `timestamp DESC, id DESC`。只用时间戳做游标时，同一时间戳的行跨页会丢失或重复。索引 `idx_recent_unpinned_ts_id` 包含 id，否则 SQLite 会退回临时排序；旧库里只含时间戳的 `idx_recent_unpinned_timestamp` 被它覆盖，打开时删除。
- 每页多取一行作为哨兵。哨兵存在才说明还有更早的记录，总数恰好是页大小整数倍时不会多出一次空翻页。哨兵在进入列表前去掉。
- 置顶、删除、改标签或清空后重新加载时，保留用户已经滚动加载的页数，列表不跳回顶部。追加的页按 id 去重：取页期间的实时事件可能已把其中一行移到最前面。
