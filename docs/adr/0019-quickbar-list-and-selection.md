# 0019 QuickBar 列表布局与选择

- 状态：已采纳

## 决定

- 行高固定为 `ROW_HEIGHT_REM`。CSS 行高、键盘滚动、列表虚拟化和 e2e 的几何断言都从这个值推导，不在别处写死。
- 每行结构固定：40px 内容区（两行文本、文件名或缩略图；有标签时为标签加一行预览）和 24px 元信息行。行内高 68px = 2 + 40 + 24 + 2，类型图标列与内容区对齐。上下透明边框配合 `background-clip` 让背景内缩 2px，相邻的选中行之间留出缝隙，行高不变。
- 操作按钮只在悬停或键盘焦点进入该行时出现，位于元信息行预留的右侧空白（`pr-[6.5rem]` 对应 4 个 1.5rem 按钮加间距），不遮住文字。按钮使用固定 id，置顶按钮切换文字和图标时 keyed each 和键盘焦点保持不变。
- 元信息用字符串拼接，因为模板里的换行在 WebKit 下会多渲染一个空格。
- 类型图标兼作多选框，操作栏里不再放多选按钮。
- 选择方式与访达一致：不按 Shift 的 ↑/↓ 移动光标并清空多选；⇧↑/↓ 从锚点扩展到光标，范围缩回一行时取消多选；没有多选时 ⇧点击只勾选该行并作为锚点。只勾选了一行时，回车使用勾选的这一行，忽略光标位置。光标所在行被删除或移出列表时，光标留在原来的位置。
- 输入法确认按键时组字可能已经结束，按键处理同时检查 `isComposing` 和 `keyCode === 229`。
- 选中行的高亮立即更新，预览正文等选择稳定后再渲染。
- 复制成功的对勾由行组件计时。行在 1.5 秒内滚出虚拟化范围时组件被卸载，对勾提前消失；作为短暂提示可以接受。
- 权限横幅放在面板内部，随三种主题变化；琥珀色只用于图标，横幅整体保持中性色调。
