# 0009 详情预览的读取上限与缓存

- 状态：已采纳

## 决定

- 预览详情在 SQL 里限制读取量：文本最多 1 MiB，图片超过 16 MiB 时不返回 BLOB。文件列表读取完整的 JSON 数组，以 `filePaths` 数组返回，按整条路径截取到合计 1 MiB，超出时 `truncated: true`；文件名可以包含换行，前端直接使用数组，不按换行拆分。复制和粘贴仍然读取完整内容。
- 文本超过 1 MiB 时返回 `truncated: true`，预览栏展示截断提示并禁用在线编辑；后端 `update_text_content` 同样校验原文长度不超过 1 MiB，防止截断草稿覆盖完整正文。
- 前端维护两类有界缓存：文本/文件详情缓存最多 16 条（单条不超过 256K UTF-16 字符），原图详情缓存最多 4 条（≤ 4 MiB 图片在选中稳定后自动加载，避免方向键切换重复跨 IPC 传输）；删除或清空历史时同步失效缓存。
- 合并粘贴通过 `get_for_merge` 读取元数据，不读取会被跳过的图片的原始字节。
