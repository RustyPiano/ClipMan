# 0003 自身复制识别与去重标记

- 状态：已采纳

## 背景

ClipMan 写入剪贴板后，监听线程会读到这次写入。它要识别并跳过自己的写入，同时和上一次读到的内容去重。

## 决定

- 标记（`CopyMarker`）只哈希主要内容。Text 只哈希纯文本，不含 HTML：自身粘贴后监听读回的是纯文本备选格式，必须仍能匹配。
- Files 哈希实际写入的路径列表。macOS 用存储路径构造 NSURL，`NSURL.path()` 原样返回；其他平台经 arboard 写入，arboard 会规范化路径并丢弃无法解析的路径，`paste::effective_file_paths` 按同样方式计算，让标记一致。
- `paste::write_with_marker` 在写入前登记标记，写入期间（例如等待文件访问授权）标记一直有效；写入成功后记录完成时间，从这时开始计算 2 秒有效期；失败时清除标记。所有写入都在 `clipboard_use_lock` 内执行，不会有另一次写入替换标记。
- 自身写入、重复内容和被排除的应用都先推进 `last_marker` 再跳过，否则之后的复制会和过期的标记比较。
- 暂停采集期间完全不读取剪贴板，`last_marker` 也不推进。恢复后第一次读到的内容和暂停前的最后一条比较，行为与没有暂停时一致。
