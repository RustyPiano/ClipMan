# QuickBar 重构验收记录

日期：2026-09-06。基于 v2.2.1，工作区实现，尚未提交或发布。

## 实现

- 保留 Tauri / Svelte / SQLite 和单个 Rust crate；没有引入 UI 框架或运行时依赖。
- 选择改为 ID；移除页面的索引/锚点互相修正及强制同步布局。多选与会话操作失效标记由同一个 selection store 管理。
- 首屏与追加分页独立序列；后台刷新不抢占正在进行的搜索。回车直接提交当前查询，最多等待 1.5 秒；输入、Esc、导航和重新呼出取消待执行意图。
- 搜索防抖 120ms → 30ms。短查询覆盖全文，搜索结果返回命中附近的 512 字符摘要、完整字节数、文件数量及第 1001 行哨兵。UI 提示截断。
- FTS 先限制候选行再生成摘要，避免为所有命中项处理大文本。
- 列表固定 4rem，两行内容，前后缓冲 4 行；滚动仅按高度计算。复制、置顶、标签、删除及多选恢复到每行；悬停/选中/键盘聚焦时显示，标签编辑不改变行高。右下角菜单只保留全局操作与说明。
- 预览可关闭，70ms 稳定后更新正文；小文本自动加载，大文本及原图手动请求；文本/文件详情最多 1 MiB，明确提示截断，复制/粘贴保持完整。原图预览上限 16 MiB，不缓存图片；SQL 在返回 BLOB 前检查大小。
- 完整详情使用 decoded ClipDetail，保留一份小文本缓存（最多 16 × 256K UTF-16 code units）。移除解码副本缓存；删除/清空后迟到的详情不回填。
- 后台刷新用一个执行中任务和待刷新标记合并连续事件；保留最后一次更新，避免重复历史/搜索请求。
- 捕获事件只在历史查询期间暂存用于合并，结束即释放；不再长期保存整份事件副本。
- 所有复制/粘贴入口合用一个执行函数及非排队互斥保护。读取与系统剪贴板写入放在 blocking pool；写入成功后隐藏、恢复焦点、发送粘贴，随后一次维护历史/托盘。
- 合并跳过图片且不读取原图 BLOB；只把实际使用的条目标记为最近使用；一次失效通知刷新完整批次。
- 复制成功后的焦点/模拟粘贴失败返回 copiedOnly，并提示手动粘贴；不会报成“复制失败”。macOS 保留权限检测、文件 URL 落地确认和 60ms 焦点等待，恢复失败或面板重新出现时不发送 Cmd+V。
- 每次呼出仍记录目标应用并检测屏幕；仅在几何变化时设置尺寸/位置和更新原生阴影。
- 初次语言跟随系统；macOS 忽略应用支持 bundle ID，兼容已有名称；其他平台提示限制。暂停采集、合并跳过图片和仅复制降级可见。
- Tab 不再切面板；Alt+Left/Right 切换，保留 Enter、修饰键 Enter、数字槽、置顶/删除/置顶排序。菜单操作可经平台键盘导航访问。


运行前需给执行终端/代理与 QA 包授予辅助功能权限；QA 设置使用默认快捷键和自动粘贴。脚本会操作桌面，结果和合成文稿保留在打印出的临时目录。托盘故障用例会临时重命名隔离库的 clips 表，在 finally 中恢复；勿将它改指向日常数据库。
本轮实际确认 ad hoc QA 包重建后旧辅助功能授权失效；用户重新授权后复测。不能把该 QA 包当作稳定签名发布包。


原生复测另发现并修复同秒排序问题：旧时间戳精度为秒，连续捕获/取用在同秒内按随机 ID 排序，直接回车可能取到上一条。捕获、去重更新和取用时间统一保留秒的小数部分（微秒来源），分页游标也保留精度。前端时间单位仍为秒，旧 INTEGER 秒数据原样可读，新记录以 REAL 秒存储；新增同秒捕获/去重/取用、分页、旧数据混读与重开回归测试。旧二进制按整数读取时间戳，不支持直接读取产生了新时间戳的数据；发布前应保留升级前数据库备份，不能把新库直接交给旧版降级使用。


## QuickBar 与本轮重构前 main 的区别

## 鼠标操作反馈修正（2026-09-06）

- 根据用户反馈，将复制、置顶/取消置顶、编辑标签、删除及多选放回每行，悬停/选中/键盘聚焦时可直接操作，无悬停能力的设备始终显示。右下角仅保留清空历史和快捷键说明。

行内操作的宽度修正：按钮改为右下角绝对定位，仅浮在元信息行上，不再永久占据文本宽度；正文和数字快捷键标记位于其上方，悬停/选中时也不被遮挡。保留行内操作、固定行高与虚拟渲染。新增 Chromium/WebKit 布局回归验证正文宽度不随按钮显示变化、正文/数字槽不与按钮重叠且复制仍命中当前行；30 项浏览器测试通过，宽窄/深色截图已检查。
