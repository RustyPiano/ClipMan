## ClipMan v2.4.3

### 新功能与体验改进

- **QuickBar 列表重新设计。** 每行更紧凑，内容预览和元信息的位置在每行都一致；正文使用比例字体，链接、JSON、命令等代码类内容使用等宽字体，换行不再从单词中间断开。
- **按内容区分的类型图标。** 左侧图标区分文本、链接、代码、图片、文件、文件夹和多个文件；鼠标悬停时变成圆形勾选框，点击即可多选。
- **来源应用图标（macOS）。** 元信息行显示复制来源应用的图标和名称。旧记录在该应用再次复制内容后也会显示图标。
- **更清楚的时间。** 今天的记录显示具体时刻，昨天的显示“昨天”，更早的显示日期。
- 操作按钮只在鼠标悬停或键盘焦点进入该行时出现，不遮挡文字；预览头部显示字符数或文件数；搜索框与面板切换统一高度。

---

### New and improved

- **Redesigned QuickBar list.** Rows are more compact and keep the preview and metadata in the same place on every row. Prose uses the proportional font, while links, JSON and commands stay monospace, and lines no longer break inside words.
- **Content-type glyphs.** The left glyph tells text, links, code, images, files, folders and file lists apart, and turns into a round checkbox on hover for multi-select.
- **Source app icons (macOS).** The metadata line shows the icon and name of the app a clip was copied from. Older clips pick up the icon once that app is copied from again.
- **Clearer times.** Today's clips show the clock time, yesterday's show "Yesterday", older ones show the date.
- Row actions appear only on hover or keyboard focus and never cover text; the preview header shows character or file counts; the search box and panel tabs share one height.
